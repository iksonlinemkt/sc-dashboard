📥 นำเข้าข้อมูล Facebook Insights

สำหรับพนักงาน — อัปโหลดไฟล์ CSV จาก Facebook เพื่อเพิ่มข้อมูลเดือนใหม่

วิธีใช้

1
เลือกสาขาของคุณ
2
ไป Facebook Page → Insights → Export Data → โพสต์ → ดาวน์โหลด CSV
3
อัปโหลดไฟล์ที่นี่ แล้วกด "ตรวจสอบข้อมูล"
4
ตรวจดู preview แล้วกด "บันทึกเข้าระบบ"
